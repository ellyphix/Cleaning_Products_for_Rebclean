# Source image assets

This folder stores the high-resolution image masters used to create or update
the optimized assets served from `public/`. These files are kept for future
cropping, format conversion, and visual regeneration; Vite does not copy this
folder into the production build.

- `products/` contains the original product renders used for the product cards.
- `use-guides/` contains the original scene images used on the four use guides.
- The top-level lifestyle and story images are the sources for the home hero
  and About story images.
- The logo PNGs preserve transparent and white-background source variants for
  primary and badge marks.
- `rebclean-hero-studio-background-v2.png` is the source for the home hero
  background.
